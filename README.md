# The 7 - Creative Design Agency Website Clone

A responsive creative design agency website clone developed using
HTML5 and CSS3.

## 📌 Project Overview

This project recreates a creative design agency website with sections
for services, recent work, blog posts, pricing plans, achievements,
team members, clients, contact information and footer.

## ✨ Features

- Responsive navigation
- Hero section
- Services section
- Recent work / portfolio section
- Portfolio category buttons
- Blog section
- Pricing tables
- Achievement section
- Team members section
- Client logos
- Contact section
- Footer with social media links
- Hover effects
- Responsive design
- Mobile, tablet and desktop layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Flexbox
- CSS Media Queries
- Responsive Web Design

## 📱 Responsive Design

The website is designed for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens
